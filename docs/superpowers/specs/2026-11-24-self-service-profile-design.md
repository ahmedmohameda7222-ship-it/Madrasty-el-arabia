# Personal greeting and self-service profile
User requested a static localized welcome plus the actual user's name on Home and a Profile page under Konto und Gerät. Web and native Android share a scoped profile API. Every role sees its own display name. Guardians may edit their own birth date, phone and optional emergency address, and an approved linked child's display name and birth date. Age is derived from birth date, not stored. Existing school identifiers, class, roles and sign-in email cannot be changed here. Direct mutations use existing CSRF, persona checks, revisions and idempotency, and recheck child link scope. School staff with students.manage can view emergency information in family detail; other users cannot. Historical audit and ordinary notification functions are not touched.
