# Family management — approved design
Mobile-first student and family directory, explicit family records, independent verified guardian access per child, optional private family situation, new-family wizard, family/student/guardian details, staged CSV/XLSX import, Web/PWA and Material 3 Android parity. Divorced/separated and blended households: family membership is organizational, never an authorization grant. Keep current child_link state/effectivity as sole guardian access authority. Keep finance payer versions and finance.issue scope, separate from guardianship. No inferred co-guardian links or legacy merges; existing people remain available in a separate legacy directory until explicitly assigned. Preserve old API callers and import templates. All examples use isolated synthetic data. No production changes until complete CI and screenshot review.
