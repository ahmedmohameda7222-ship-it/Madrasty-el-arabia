## Three journeys to rerun after any cross-domain fix in final QA

1. **Student affairs → new family.** Create year/class, set class lead and subject teaching, enroll siblings, import second guardian then repeat import. Invite parents, select correspondence languages, confirm each sees only the children and contact details they are authorized for. A removed link cuts academic and messaging access; named-payer historical access follows its own rule.
2. **Parent → teacher → office.** Family marks a scheduled absence, teacher sees reason and locked row, teacher records actual arrival or approves unexcused absence for a different child. Reconnect an older offline sheet, resolve only the changed row. Verify exactly one eligible private notification and routed office follow-up where applicable.
3. **Accounts → family → management.** Bill Ahmed and Omar individually, record only Ahmed's external payment, request next-month pause for Omar. Office reviews, accounting sees any balance requiring reconciliation, school receives the right dashboard queue, open reminders follow the decision and Ahmed's receipt is preserved.
